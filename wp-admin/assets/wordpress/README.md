# WordPress design-system icons

These five SVGs are unmodified exports from the WordPress.org [WordPress Design System](https://www.figma.com/community/file/1436359662053949167/wordpress-design-system). The Community listing identifies its license as [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The supplied working file is `JFAsdPvtrs7rJhIJdlRu3g`:

- `search.svg`: SearchControl, node `3025:46628`.
- `plus.svg` and `minus.svg`: NumberControl, node `14488:24375`.
- `bold.svg` and `italic.svg`: Toolbar, node `18344:130894`.

All five exports have a natural size of 24 × 24 pixels. Administration uses the local files at that size; there are no temporary Figma asset URLs in the runtime. Logos, documentation-cover illustrations and demonstration photographs from the reference boards are not part of the application's interface.
