# Architectural invariants

| Invariant | Enforced boundary |
| --- | --- |
| PHP 8.4+, SQLite 3.45+, mandatory extensions | Configuration and installation checks |
| WAL with reliable local locking | Connection-level request and verification; deployment responsibility for filesystem suitability |
| Atomic content, revision history, and outbox | One BEGIN IMMEDIATE commit |
| Authoritative authorization | Re-read and recheck inside the transaction; permission gate before draft/editor reads |
| Separate Post/Page capabilities | One capability evaluator for both types |
| Monotonic revisions | WHERE id = :id AND revision = :expected_revision |
| Fenced workers | Active non-expired lease_token checked before side effects and completion |
| Fresh public materialization | rendered_revision === revision; otherwise sanitized live rendering |
| Safe HTML | DOM element/attribute/protocol allowlists, actual wrapper identity, escaped fallback without DOM |
| Login work admission | Atomic per-IP fixed-window reservations before password verification; forwarded headers are not trusted |
| Local uploaded images | Complete decoding and re-encoding, metadata removal, bounded memory, orientation preservation, animation rejection |
| Published image policy | Site-local content-addressed uploads only; enforced by sanitization and CSP |
| Local redirects | Reject backslashes, controls, protocol-relative URLs, malformed schemes, foreign host/port, and credentials |
| Request authenticity | Action/session-bound CSRF tokens on modifying POSTs; no GET logout |
| Revocable authentication | Hashed opaque tokens, server expiry, explicit deletion/revocation |
| Per-site secrets | Unique generated auth.key or operator secret; no hardcoded shared fallback |
| Non-executable runtime registry | Validated JSON only; no require of cache artifacts |
| Private state and source internals | Server denies hidden descendants, var, docs, vendor, tests, tools, bin, wp-includes, and PHP under wp-content |
| Blank distribution | No installed state, uploads, credentials, secrets, or development dependencies |

Public uploads are intentional. Theme PHP is trusted source, and the editor does not install executable code. Extension absence is a deployment error even though the sanitizer itself fails closed to escaped text.

Asset storage operations and backup file reads acquire the common storage lock before database write locks. Cleanup removes only canonical, regular files with no referencing media row and a 24-hour orphan grace period. Unknown files and symbolic links are preserved. Incomplete and non-image records are excluded from existing image consumers. Document upload and routed delivery are enabled under the asset state machine: only ready records are deliverable, authorization is rechecked on every request, and private documents answer with an indistinguishable 404. Image variants and edited copies are derived records pointing at their master: derivation grants no access and changes no attribution, an interrupted derivation is completed or removed by maintenance, and replacing an image moves only current featured, block and shared-section references after a full permission check — avatars, the site logo and all revision history keep the original.

Design/file publication rechecks administrator authority and expected live version inside the write transaction. Draft previews are session-bound and never mutate live configuration. A theme health failure leaves live design unchanged. Managed files use fixed names and fixed MIME; executable PHP, configuration, uploads and arbitrary paths are outside the editor. Shared-section/design-history image references are protected from media removal. Document references in content are validated for the author's access at save and again inside the write transaction; publication additionally requires a public document.

Page selection in Site design is request-local and cannot assign the homepage or persist a design. Page inventory and private selection require current administrator access and separate action-bound nonces. Default responses retain DENY/frame-ancestors none. Only an existing, editable, nontrashed Page in explicitly requested visual workspace mode, with a session/action/Page-bound nonce and current administrator permission, receives SAMEORIGIN/frame-ancestors self. Its native authenticated editor is trusted application code; the separate public-content canvas and live preview remain script-disabled. Parent/child messages require the exact same origin, active frame/parent and Page ID. Content saves use the original nonce/revision controller; they never publish the site design.

Workspace New Page is an explicit administrator POST with its own action-bound nonce. The application supplies Page type, Draft status, authenticated author, empty version-1 block document and curated Standard template to the existing mutation service; caller-supplied content fields and the site's default status cannot override those defaults. Creation never changes homepage/design options. Client activation is blocked while pending; ambiguous responses are not retried automatically. This is a client pending-operation guard, not a durable cross-request idempotency contract.

Workspace Save Draft, Publish Page and Update Page are native submitters for the existing Page form. A pure, workspace-scoped intent map fixes their target statuses to Draft, Published and Published respectively; a hidden/submitted status cannot reverse that intent. Other editor modes retain their original status handling. The existing mutation service remains authoritative for current edit/publish permission, expected revisions, content validation and atomic writes. Failed saves preserve submitted content and restore the displayed saved status. Success labels and action availability use the persisted record; result parameters are restricted to the known actions. The keyboard save shortcut targets Save Draft or Update Page, never Publish Page.

Portability is administrator-only at every entry point (admin screen and CLI operator context). Export is a POST with an action nonce and includes private document bytes; it is a backup-class disclosure and changes nothing. Import writes happen only after a preflight report and a separate confirm step with its own nonce. Archive parsing enforces entry-count, per-entry and total size caps, rejects absolute and parent-traversing entry paths, and parses WXR with network access and entity expansion disabled. Media enters only from the supplied archive through the normal intake validators and quota — there is no remote fetching path, and imported PHP, shortcodes and plugin data are never executed. Relationships are rebuilt through an explicit source-to-target ID map; source database IDs and source role data are never trusted, and unmapped authors become ordinary accounts whose password hash corresponds to no known credential. Run state is keyed by archive digest plus author mapping in a site option; completed items are reported as already imported on a re-run instead of being duplicated. No schema change was needed for any of this.

Discovery output (the RSS feed, the XML sitemap, robots.txt and social metadata) is limited to published, public content, enforced in the queries rather than by filtering rendered output: drafts, archived and trashed items, previews and private documents never appear, and an item that leaves publication disappears on the next request. The feed carries excerpts only — never body content — and author data is limited to display names; account contact data (email addresses) appears in no feed, sitemap, robots or head output. All metadata output is escaped for its context (strict XML escaping without CDATA in feed and sitemap; attribute escaping in head tags). Indexing control is a single site-wide option: while discouragement is on, pages carry a noindex robots meta and robots.txt disallows all crawling, but the feed and sitemap stay available; there is no per-entry noindex. A social image resolves only from ready image records — the per-entry override first, then the featured image — so a document or a stale reference can never be emitted as one.
